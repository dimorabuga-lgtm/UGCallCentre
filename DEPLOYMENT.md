# Deployment guide

1. Купіть домен, налаштуйте DNS і увімкніть HTTPS.
2. Замініть `ugcallcentre.com.ua` у SEO-файлах та `_next` FormSubmit.
3. Розгорніть статичний каталог на Netlify, Vercel, Cloudflare Pages або GitHub Pages.
4. Застосуйте рекомендації з `headers.example`: CSP, HSTS, frame/options, permissions, referrer, COOP, COEP, CORP, gzip/Brotli і cache-control.
5. Додайте й підтвердьте Search Console, GA4, GTM, Meta Pixel та Clarity після отримання їх ID.
6. Надішліть sitemap у Google Search Console і перевірте robots.txt.
7. Пройдіть Lighthouse, Core Web Vitals, FormSubmit, cookie-consent і cross-browser перевірки.
